# RIFT // SALVAGE

iPhone Safari 向けの独立したオリジナルSFターン制脱出ローグライク（開発版）。

## ブラウザで遊ぶ

GitHub Pages の公開後は https://souten-yd.github.io/RIFT-SALVAGE/ から起動できます。

このリポジトリは静的サイトです。アプリのメイン画面は `index.html` で、ゲームコード・CSS・画像はHTMLに内蔵しています。サーバでビルドや実行を行う必要はありません。

- 任務を選択して「出撃する」
- マップをタップして移動、射撃・リロード・治療
- 目標端末と物資を回収して、脱出地点へ戻って撤収
- 帰還後、母艦で装備と永続強化を管理
- Safariの「共有」→「ホーム画面に追加」でアプリのように起動

v0.4 IRON VEIL。iPhone実機での60fpsは未計測です。

## 配布・検証

`index.html` だけで起動するため、GitHub Pagesにmainブランチのルートを公開設定します。公開設定後に公開URLで動作を確認してください。

開発はPRを基本とし、mainのファイルと実際の挙動を検証してからマージします。
